# Computational Physics, Dynamical Systems & Scientific ML

Working on problems at the intersection of **physics, scientific computing and machine learning**.

My current work focuses on **dynamical systems, inverse problems and deep learning for physical systems**, including the development of computational environments and benchmarks for evaluating learning-based methods on scientific problems.

I am especially interested in problems involving **numerical simulation, nonlinear dynamics, physical modelling and data-driven approaches**.

## Current focus

- Inverse problems with deep learning
- Scientific machine learning benchmarks and evaluation environments
- Numerical simulation and computational physics
- Computer vision and scientific image processing

## Broader interests

## Selected projects

Satellite-image analysis of Hurricane Dorian using MATLAB.

The project includes:

- Eye detection and temporal tracking
- Translation-speed estimation
- RGB-based angular motion estimation
- Scientific visualization and quantitative analysis
